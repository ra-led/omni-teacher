How Omni Teacher works

From topic selection to reflections, every step is backed by structured data models: programs, lessons, attempts, badges, and chat sessions.

Step 01

Student picks a topic

From a kid-friendly catalog like “Fractions with Pizza” or “Story Writing Adventure”.

Step 02

Diagnostic quiz

QuizGen uses the LLM Orchestrator to build a short, tailored quiz. Students answer by text, voice, or pictures.

Step 03

Program assembled

Results feed into a personalized program_version: chapters, lessons, quizzes, and preferred modalities.

Step 04

Lesson chat & reflection

Lessons run as structured chat sessions. Attempts and reflections update progress, badges, and recommendations.

Architecture built for scale and safety

Investors get more than a demo. Omni Teacher is a containerized, observable platform with clear separation between UI, orchestration, workers, and storage.

Next.js · FastAPI · Async workers · Postgres · Redis · MinIO

Modular, production-ready stack

  • Frontend: Next.js web app with chat & lesson UI, curriculum catalog, and progress dashboards.
  • Backend: FastAPI REST & WebSocket API with RBAC for students, parents, and admins.
  • Orchestration: LLM Orchestrator managing prompts, tools, and post-processing for gpt-4o multimodal reasoning.
  • Workers: Async quiz evaluation, TTS synthesis, and vision analysis running on Redis-backed queues.
  • Persistence: PostgreSQL for learning data, Redis for cache/queues, and MinIO/S3 for media.
DevOps ready

Dockerized services, docker-compose for local, Prometheus + Grafana + Loki for observability, and GitHub Actions for CI/CD with ephemeral test environments.

System at a glance

Frontend: Next.js Web App └─ Chat & Lesson UI └─ Program Catalog └─ Voice Recorder Backend: FastAPI API ├─ Auth & RBAC ├─ Progress Tracking ├─ Quiz & Program Generator └─ Media Pipeline Orchestrator → gpt-4o (LLM/VLM) Workers → Quiz / TTS / Vision Storage → Postgres, Redis, MinIO

Safety, compliance & control

Omni Teacher is designed for children first: friendly personas, strict guardrails, and reporting that adults can trust.

COPPA/GDPR awareness · Content moderation · Human-in-the-loop

Child-safe persona

System prompts keep tone age-appropriate, encouraging, and on-topic — nudging students gently back to learning.

Content moderation

Omni classification and filters review messages before they are shown or stored, with escalation to human review if needed.

Privacy by design

Parental consent, data minimization, and clear separation of student vs guardian accounts support COPPA/GDPR-aligned flows.

Audit-ready logs

Structured records of programs, quizzes, attempts, and badges provide a defensible trail for schools and regulators.
